截至26年5月，启动新规范的模型文件，需要进入components/model_05目录，使用指令：
cd ./workflow/components/modem_05
python LSTM_20250424.python

截至26年5月，新规范的模型文件的可视化提供2个可调参数：
is_export   True表示不进行窗口显示，进行持久可视化；False表示进行窗口显示，不进行持久可视化。
opt_path    混淆矩阵、损失准确曲线的输出路径；同时，当需要持久化输出模型测试可视化时，可视化png图片将会输出在该目录下

截至26年5月，模型测试结果可视化的执行规范是这样的：
假设当前选定3个测试文件file1、file2、file3；测试文件中除时间戳、标签以外，有n个数据特征；
模型在持久化导出png图片时，将会在opt_path下创建3个目录，目录名与测试集文件名同名；
各个目录下：将会持久化保存n幅png图片，每幅图片包含如下元素：
    图片名：数据特征名称
    横坐标：时间轴
    左侧纵坐标：数据特征的赋值
    右侧纵坐标：模型预测的回归概率，赋值0-1
    红色背景：人工标记的卡顿区间
    蓝色背景：模型预测的卡顿区间
    紫色背景：如果人工标记的卡顿区间，也被模型准确预测了，那么这部分的重叠部分将会被标记为紫色背景
